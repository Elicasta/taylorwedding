# Taylor Wedding Proposal

Private editorial proposal microsite for EC Creative Studios / Emma Cast Weddings.

## Quote link

Set the real client quote URL once in `script.js`:

```js
const QUOTE_LINK = "https://your-real-quote-link.com";
```

Every booking CTA on the proposal will use that URL automatically.

## Deployment

This is a zero-build static site. Vercel can deploy the repository directly.

## Privacy

The page includes `noindex,nofollow` so search engines should not index the proposal.
